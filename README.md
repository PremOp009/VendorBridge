# VendorBridge
### Procurement & Vendor Management ERP Platform

VendorBridge is a modern full-stack Procurement & Vendor Management ERP system designed to simplify and digitize organizational purchasing workflows.

The platform helps companies manage:
- Vendors
- RFQs (Request for Quotations)
- Vendor Quotations
- Procurement Approvals
- Purchase Orders
- Invoice Generation
- Procurement Analytics
- Activity Logs

VendorBridge centralizes procurement operations into a single intelligent platform, reducing manual workflows, improving vendor communication, and enabling smart procurement decisions.
